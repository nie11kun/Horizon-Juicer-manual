# 第 9 章 磨削中心复合功能

当在 `HorizonJuicerCreator` 中配置为 **内螺纹 + 磨削中心（`ifIsCenter`）** 后，设备集成了外圆磨削、外圆双台阶磨削、左右端面磨削以及内螺纹/自动对刀等四维复合功能，全部动作由核心调度程序 **`A_GRIND_CENTER.SPF`** 统一指挥。

磨削中心按“**总控调度 + 分工序独立参数**”组织画面，所有参数界面的底部软键栏共享统一快速切换入口（`HS1`～`HS8`）：

- [9.1 加工选择看板与多工序联合调度](center_overview.md) —— 掌握 `加工选择` 三合一监控面板（`a_centermain.com`）、右侧绿灯工序组合与独立修整铁律；
- [9.2 外圆与外圆台阶磨削及修整](cylindrical_and_step.md) —— 详解 `U` 轴 vs 共用 `X` 轴外磨、`保持分段` vs `来回` 策略、退刀槽跳过、`偏转补偿角` 与外圆双台阶编程；
- [9.3 左右端面磨削、修整及交叉补偿](endface_grinding.md) —— 详解耳高/壁厚起止点自动解算、独立 4 列端面工艺及外圆-端面修整坐标双向自动联动。
