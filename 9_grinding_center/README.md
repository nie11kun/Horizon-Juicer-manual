# 第 9 章 磨削中心复合功能

当在 `HorizonJuicerCreator` 中配置为 **内螺纹 + 磨削中心（`ifIsCenter`）** 后，设备集成了外圆磨削、外圆双台阶磨削、左右端面磨削以及内螺纹/自动对刀等四维复合功能，全部动作由核心调度程序 **`A_GRIND_CENTER.SPF`** 统一指挥。

磨削中心按“**总控调度 + 分工序独立参数**”组织画面，所有参数界面的底部软键栏共享统一快速切换入口（`HS1`～`HS8`）：

- [9.1 加工选择看板与多工序联合调度](center_overview.md) —— 掌握 `加工选择` 三合一监控面板（`a_centermain.com`）、右侧绿灯工序组合与独立修整铁律；
- [9.2 外圆与外圆台阶磨削及修整](cylindrical_and_step.md) —— 详解 `U` 轴 vs 共用 `X` 轴外磨、`保持分段` vs `来回` 策略、退刀槽跳过、`偏转补偿角` 与外圆双台阶级联编程；
- [9.3 左右端面磨削、修整及交叉补偿](endface_grinding.md) —— 详解耳高/壁厚起止点自动解算、独立 4 列端面工艺及外圆-端面修整坐标双向自动联动。

## 磨削中心串联顺序与 3 条防撞安全铁律

在 `AUTO` 模式下，`A_GRIND_CENTER.SPF` 固定按 **外圆（`H_GRINDING.SPF`）→ 左/右端面（`L_GRINDING.SPF`）→ 外圆台阶（`Q_GRINDING.SPF`）→ 内螺纹（`B_SCREW.SPF`）** 顺次执行已点亮的工序开关。实机调试必须恪守以下 3 条红线：

1. **单砂轮独立修整铁律**：手动点亮 MCP **`修整键`** 对任一把砂轮修整前，务必先回到 **`HS7 加工选择`**，**仅保留当前待修砂轮对应的绿灯开关，熄灭其余全部工序开关**，防止误联动其他砂轮轴系造成干涉撞机；
2. **外圆/端面双向修整标定**：每次更换新外圆砂轮或首次装配后，必须**同时重标**外圆与左/右端面的修整起止点及初始磨削接触位，以保证两套坐标系双向交叉补偿准确；
3. **共用 `X` 轴防干涉退刀位**：无独立 `U` 轴、外圆与内磨共用 `X` 轴的机型，务必精确设定 **`外圆退刀位`（`INI[107]`）** 与内螺纹 **`台面起始位置`（`INI[28]`）**，确保内磨深入孔内时外圆砂轮处于绝对安全退避区。
