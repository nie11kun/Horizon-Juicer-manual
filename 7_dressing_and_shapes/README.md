# 第 7 章 砂轮修整、滚轮与齿形模型

在螺纹与复杂型面磨削中，砂轮截形的几何精度直接决定工件最终中径、牙型角与滚道接触角质量。`Horizon-Juicer` 将整套修整体系清晰地划分为三层画面：**修整主参数（`a_dress.com`） → 滚轮校准（`a_dressware.com`） → 齿形模型（`a_shapecommon.com`）**。

## 1. 修整主循环执行流程（`B_DRESS.SPF`）

无论通过 **手动点亮修整键（<code>&#36;A_DBB[0]</code>）** 执行独立修整，还是在 **磨削/工艺中自动触发修整**，NC 核心子程序 `B_DRESS.SPF` 均严格按以下流程运转：

1. **砂轮档案切换检测**：若当前为 **新砂轮**（`DRESSER[5] == 0`），自动将 `CUR_WHEEL` 指针递进至下一记录槽（`1~99`）并记录换轮时间、清零本轮计数；
2. **参数传递与自检初始化（`C_DRESS_CHOICE` / `C_DRESS_START`）**：判定修整模式、计算本次修整切深，并核对当前砂轮直径是否越过 `最小磨削直径`（`DRESSER[35]`）等 14 项报警条件；
3. **中心与轮廓位置初始化**：
   - 对于插补型修整器（`VW`/`XZ`/`XW`/`UW`），依次调用 `C_WHEL_SHAPE` 与 `C_DRESS_SHAPE_INIT`；
   - 对于成型滚压轮或液压摆缸，调用 `C_DRESS_INIT_POSITION_CX`；
4. **启动双主轴与冷却液**：判断 `UW` 力矩夹紧轴开关后分别以线速度/定转速启动 **砂轮电主轴** 与 **修整滚轮轴**，并打开 `M28` 修整冷却液；
5. **循环轮廓切削（`C_DRESS_SHAPE` → `C_DRESS_CALC`）**：
   - 实时监测 <code>&#36;A_DBB[2]</code> 退刀键与每 20 次刷新的线速度重算；
   - 新砂轮模式下如开启 **独立轮廓修整参数**，先将轮廓从顶部或半宽逐步成型后再收敛精修；
6. **结束退回（`M29` 关冷却 → 退回停泊位 → 停滚轮）**：返回安全位置，若设定了 **磨削中每次修整位置补偿**（`DRESSER[70]`）则同步累加至后续磨削进刀位。
