# 10.1 报警代码对照表与现场常见问题

## 1. NC 核心工艺与修整报警表（`C_ALARM.SPF` / `DRESSER[6]`）

当任一子程序自检或动态监测到工艺逻辑越限时，会给全局变量 `DRESSER[6]` 赋入对应报错号（`1 ~ 14`），随后在主流程末尾统一由 `C_ALARM.SPF` 输出对应语言提示（自动识别中文/英文/俄文）并执行 `M0` + 长延时锁定程序，防止危险运行。按 **RESET** 清除报警状态后依下表修正参数：

| `DRESSER[6]` | 屏幕提示信息（中文） | 触发原因分析 | 现场处理对策 |
| :---: | :--- | :--- | :--- |
| **`1`** | `工件左端坐标>工件右端坐标` | 在 `磨削参数` 输入的 `工件左端` 数值错误大于 `工件右端`（或两值颠倒） | 重新核对坐标系并正确记录工件左端、右端 Z 轴坐标；或临时先设一组合理的有效坐标后再纯修整 |
| **`2`** | `砂轮过小,请更换新砂轮!` | 当前砂轮直径 `DRESSER[24]` 小于设定 `最小磨削直径` `DRESSER[35]`（或推算下次修整后将小于最小直径） | 更换新砂轮并将修整参数切换至 `新砂轮`，重新测录新直径与初始接触位；若尚有余量需核对 `最小磨削直径` 设置 |
| **`3`** | `砂轮过大,请将砂轮修整到小于最大磨削直径!` | 当前砂轮直径 `DRESSER[24]` 大于设定 `最大磨削直径` `DRESSER[49]` | 点亮 **修整键** 执行新砂轮修整，将砂轮修小到 `最大磨削直径`（内孔安全直径）以下后再加工 |
| **`4`** | `工件外径设置有误!` | 自动对刀或外径校验中所需 `工件外径`（`INI[34]`/`INI[120]`）未输入或 $\le 0$ 越界 | 在对应界面核对并输入正确工件外圆直径 |
| **`5`** | `测头无法进入孔内,请检查参数设置!` | 内螺纹自动对刀检测反向孔时，测头按预定角度和偏心无法顺利进孔（触碰孔壁或未开启孔周探测） | 检查 `反向孔测量角`、`距右端距离`、`Z 起点`、`测头中心位`、孔圆/腰型参数，或开启 **孔周探测**（`TECHNOLOGY[155]=1`） |
| **`6`** | `检测不到信号,检查测量位.X是否合适!` | 接近开关扫描时在预定行程内未收到触发反馈（<code>&#36;A_PROBE</code> / <code>&#36;AC_MEA</code> 未响应） | 确认传感器供电及 `DB2700.DBX1.0/1.1` 状态灯能正常触发，微调 `测量位.X` 令传感器进入有效感应区 |
| **`7`** | `测头距离工件过远,或检测位置太靠外侧!` | 测头移动完整行程仍未接触工件表面 | 核对 `测头中心位`、`外圆直径`、`右端测量设置` 或传感器伸出机械限位，适当往安全方向缩短空程距离 |
| **`8`** | `工件长度设置有误!` | 外圆长度/左右端坐标推算长度 `<= 0` 或不符合 `保持分段`/台阶要求 | 检查磨削中心 `外圆长度`（`INI[30]`）及左右端接触坐标 |
| **`9`** | `外圆砂轮过小,请更换新砂轮!` | 磨削中心外圆砂轮当前直径 `DRESSER[91]` 低于外圆 `最小磨削直径` `DRESSER[137]` | 更换外圆砂轮并切回 **新砂轮** 状态，重标外圆及端面初始接触位 |
| **`10`** | `变螺距设置有误!` | 开启了多螺距变换但分段位置坐标未呈单调递增/递减排序或目标螺距 `<= 0` | 进入 `磨削参数 → VS5 螺距变换`，核对 `位置 1~6` 顺序与螺距值 |
| **`11`** | `外圆跳动:XXmm,工件圆度过大!阈值:XXmm` | 磨削中心自动对刀测得三点外圆跳动 `INI[133]` 大于 `外圆跳动阈值` `INI[127]` | 重新找正装夹工件、清理卡盘铁屑或核对三点测量角度后复测 |
| **`12`** | `工件右端过长，检查是否放置有误或重新设置右端磨削位置` | 磨削中心实测右端面坐标与 `右端测量设置` 误差超出 `右端测量阈值` | 检查毛坯来料长度是否超差或卡盘未顶靠贴实；如确为新基准则重新输入 `右端测量设置` 与端面初始位 |
| **`13`** | `工件左端过长，检查是否放置有误或重新设置左端磨削位置` | 磨削中心实测左端面坐标与 `左端测量设置` 误差超出 `左端测量阈值` | 同上，核查毛坯长度与耳高或重校左端测量基准 |
| **`14`** | `修整轮生命周期已到，请更换并重置修整量累计次数及修整量` | 修整轮已修整次数 `TECHNOLOGY[136]` 达到额定寿命 `TECHNOLOGY[135]` | 更换新金刚石滚轮，进入 **CUSTOM → 加工统计** 点击 `VS4 重置修整轮计数` 清零后继续 |

## 2. 其他常见系统级提示与故障排查（FAQ）

| 问题分类 | 现象 / 报警内容 | 原因排查与解决 |
| :--- | :--- | :--- |
| **配件寿命报警** | `"滚轮/夹具/金刚笔一/金刚笔二寿命不足，请更换!"` 并 `M0` 停机 | `SERVICE_LIFE[10..13]` 超过阈限（`SERVICE_LIFE[5..8]`）。进入 **CUSTOM → 加工统计** 的配件寿命表核实更换后重置计数（见 [5.3 节](../5_custom_and_system/stats_and_life.md)） |
| **加密授权报警** | `"设备未授权,请联系厂家！"` | 开启了 `加密保护` 且 CF 卡硬件序列号 <code>&#36;MN_HW_SERIAL_NUMBER</code> 不匹配。联系设备原厂核对序列号与授权程序 |
| **侧门安全阻塞** | 提示 `"等待侧门关闭"` 无法进入自动加工 | `TOOL_SET[18]=1` 且侧门信号 <code>&#36;A_DBB[80]==0</code>。关紧磨削中心侧防护门并确认限位开关触发到位 |
| **SinuTrain/真机改后界面没变** | 更新 `System-CF-Card` 后文本仍显示旧词或 `?` / <code>&#36;85xxx</code> | 未刷新语言缓存！请按 [4.2 节](../4_deployment_and_sinutrain/sinutrain_simulation.md) 删除 `sys_cache/hmi/hlp`，进入 **调试（Setup）** 页面后直接点击右侧垂直软键 **`VS3 Change language`** 来回切换一次语言强制重读（**切勿点底部 `HS5 HMI`**） |
| **点启动只备份或磨卡盘不磨工件** | 循环启动无动作、数据被覆写或直接走空/磨卡爪 | 上次调试忘记关闭特殊模式开关！请依次检查：<br>① **备份恢复** `模式选择` 是否忘了改回 `0 加工`；<br>② **空运行** `使能`（`GRIND[9]`）与 **自磨夹具** `使能`（`INI[68]`）是否均为 **关** |
| **输入数值报错或自动恢复原值** | 修改中径/进给量/头架转速/安全位置时被拒绝 | 触及 **系统配置 → 第六类参数输入限制** 保护阈值（默认中径 `±1 mm`、非粗磨进给 `±0.1 mm`、转速 `60 RPM`、内磨安全 Z 距右端 `>= 30 mm`）。或右侧小锁未解锁 |
| **纯修整也提示磨削位置报警** | 仅点亮修整键修砂轮，却提示左端>右端等报警 | 程序运行前会先经过 `C_PAR_INI` 统一初始化检验，须先在 **磨削参数** 页填入大致有效的左/右端及退刀位置后再修整 |
| **解锁配置页报缺失/无效** | `a_setting.com` `Mask0` 提示 `配置丢失` / `配置缺损` / `配置无效` | 检查 `/user|oem|siemens/sinumerik/hmi/cfg/machine_sec.ini` 是否随包完整导入、无手工改动字段（见 [3.1 节](../3_creator_tools/password_calculator.md)） |
