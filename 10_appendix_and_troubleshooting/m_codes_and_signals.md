# 10.2 M 代码、PLC-NC 交互信号与机械手接口

本节完整汇总 `Horizon-Juicer`（`M-sympol_Index.md` 与 `Parameter_Index.md`）使用的全部自定义 M 代码、PLC-NC 交换字节、高速 I/O 量仪信号以及桁架机械手握手协议，供电气 PLC 工程师与现场调试核查。

## 1. 全系统 M 代码清单（`M0` ～ `M99`）

| M 代码 | 含义与功能定义 | M 代码 | 含义与功能定义 |
| :---: | :--- | :---: | :--- |
| `M0` | 程序停止（系统） | `M50` | 排屑器停止 |
| `M1` | 可选程序停止（系统） | `M51` / `M52` | 静压泵启动 / 停止 |
| `M2` / `M30` | 主程序结束（系统） | `M53` / `M54` | 液压修整前进 / 返回 |
| `M3` / `M4` / `M5` | 伺服主轴正转 / 反转 / 停止（系统） | `M55` | 自动对刀按键灯关闭 |
| `M6` | 刀具更换（系统） | `M57` | 退刀按键灯关闭 |
| `M8` / `M9` | 内磨冷却 Pump 1 启动 / 停止 | `M58` / `M59` | 修整器低头 / 抬头 |
| `M10` / `M14` | 尾架回退 / 伸出 | `M60` | 外圆修整器未回退到位报警 |
| `M11` / `M12` | 润滑启动 / 停止 | `M61` | 手动对刀按键灯关闭 |

| `M16` / `M18` | 360 功能异步子程序调用 / 按键关闭 | `M63` / `M65` | 变频修整轮 1 正转 / 停止 |
| `M17` | 子程序结束（系统） | `M66` / `M67` | 安全门锁开 / 关 |

| `M22` | 砂轮修整程序启动 | `M71` / `M72` | 液压尾架顶紧 / 松开 |

| `M26` / `M27` | 电气控制箱空调启动 / 停止 | `M75` / `M76` | 液压卡盘夹紧 / 松开 |

| `M33` / `M34` | 测量机构 1 伸出 / 回退 | `M79` | `Z1` 力矩电机测试前进后退按钮关闭 |

### 桁架机械手专控握手 M 代码（`M80` ～ `M89`，需勾选 `机床机械手`）

| M 代码 | 置位/复位 `DB4900` 对应位 | 物理定义与机械手含义 |
| :---: | :--- | :--- |
| `M80` / `M81` | <code>&#36;A_DBB[60]</code> = `1` / `0` | 罩壳顶部门已打开（**备妥信号**有效 / 复位） |
| `M82` / `M83` | <code>&#36;A_DBB[61]</code> = `1` / `0` | **预完成**，提前通知机械手准备抓放料 / 复位 |
| `M84` / `M85` | <code>&#36;A_DBB[62]</code> = `1` / `0` | **机床故障**信号有效 / 清除 |
| `M86` / `M87` | <code>&#36;A_DBB[63]</code> = `1` / `0` | **尾架顶尖缩回到位**信号置 1 / 置 0 |
| `M88` / `M89` | <code>&#36;A_DBB[64]</code> = `1` / `0` | **尾架顶尖伸出到位**信号置 1 / 置 0 |
| `M92`～`M97` | <code>&#36;A_DBB[65/66/67]</code> = `1` / `0` | 卡盘松开到位（`65`）、卡盘夹紧到位（`66`）、旋转头架吹气清洁结束（`67`） |

## 2. PLC-NC 交换变量表（<code>&#36;A_DBB</code> ↔ `DB4900` & ONE 迁移说明）

> **Sinumerik ONE 兼容性提示**：当 `HorizonJuicerCreator` 选择 **系统类型 = `2`（Sinumerik ONE）** 时，自动依据 `oneReplace.json` 将老式 <code>&#36;A_DBB[...]</code> 与 DB4900 变量批量映射为 ONE 体系的 <code>&#36;A_IN[...]</code> / `digitInpVal[...]`，并将对应界面软键及报警连接改为 `DB10.DBX107.0/1` 等格式。下表为标准 828D/840D sl 基线映射：

| NC 变量 | PLC 地址 | 功能含义说明 |
| :--- | :--- | :--- |
| <code>&#36;A_DBB[0]</code> | `DB4900.DBX0.0` | 是否修整按键态（840D sl 亦可映射 <code>&#36;A_IN[11]</code>） |
| <code>&#36;A_DBB[1]</code> | `DB4900.DBX1.0` | 是否手动对刀按键态 |
| <code>&#36;A_DBB[2]</code> | `DB4900.DBX2.0` | 是否退刀（触发 `PLCASUP1` 异步动作信号） |
| <code>&#36;A_DBB[3]</code> / `[4]` | `DB4900.DBX3.0` / `4.0` | 液压动作回退到位 / 伸出到位 |

## 3. 快速 I/O 量仪与测头硬件信号

| 变量接口 | 信号用途 |
| :--- | :--- |
| **<code>&#36;A_IN[1]</code> ～ <code>&#36;A_IN[4]</code>** | 在线测量仪阶段控制反馈：`sr`（1）、`st`（2）、`f2`（3）、`f3`（4） |
| **<code>&#36;A_IN[10]</code> / <code>&#36;A_IN[11]</code>** | 在线测量 `自动模式` 信号 / `就绪` 信号 |
| **<code>&#36;A_IN[15]</code>** | 粗磨 **消空程** 碰撞/声发射输入信号（`TECHNOLOGY[293]=1` 使用） |
| **<code>&#36;A_OUT[3]</code>** | 在线测量仪测量启动输出（`1` 启动 / `0` 结束） |
| **<code>&#36;A_PROBE[1/2]</code>** & **<code>&#36;AC_MEA[1/2]</code>** | 测头 1/2 实时偏转状态与测量任务锁存捕获标志（`DB2700.DBX1.0/1.1` 为界面指示灯读取点） |
