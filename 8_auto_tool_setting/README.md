# 第 8 章 自动对刀系统

对于大批量生产、内螺纹深孔视距受限或反向孔相位严苛的场景，`Horizon-Juicer` 配备了完整自动寻位对刀子系统（`C_OPERATION_AUTO.SPF` + `D_PROBE_DETECT_*.SPF` + `F_PROBE_*.SPF`）。只要在 `HorizonJuicerCreator` 勾选 **自动对刀** 并配置相应测量装置，即可使用 **CUSTOM → 磨削界面 → `HS4 自动对刀`**（`a_auto.com`）。

## 1. 硬件传感架构与核心接口信号

本系统全面兼容 **电感/涡流式接近开关**（通常用于非接触扫描外螺纹牙槽或内滚道波峰/波谷）与 **接触式高精度触发测头（如雷尼绍工业测头）**，甚至支持双测量机构并行挂载：

| 测量装置配置 | 涉及变量与 PLC 到位检测信号 | 测量触发与任务完成标志 |
| :--- | :--- | :--- |
| **接近开关**（`TOOL_SET[31]=1`） | 机构序号 `TOOL_SET[51]`（`0`=机构 1，`1`=机构 2）：伸出/缩回到位检测 <code>&#36;A_DBB[7/8]</code> 或 <code>&#36;A_DBB[20/21]</code>（可用 `INI[157/160]` 控制是否强等开关） | 实时读取测头/开关偏转输入与状态位（如 `DB2700.DBX1.0` / `DB2700.DBX1.1` 界面状态灯，`0` 未触发 / `1` 触发） |
| **接触式测头**（`TOOL_SET[49]=1`） | 机构序号 `TOOL_SET[52]`（`0`=机构 1，`1`=机构 2）：支持与接近开关各自独立的汽缸伸缩控制 `F_PROBE_M_OUT` / `F_PROBE_M_BACK` | NC 底层实时执行西门子标准高速测量循环 **<code>&#36;A_PROBE[1/2]</code>**（当前偏转）与 **<code>&#36;AC_MEA[1/2]</code>**（任务锁存：`0`=准备测量，`1`=已碰撞捕获，脱开不变直至下次启动置零） |

## 2. 一次检测 vs 两次慢速复测策略（`INI[159]`）

在 **系统设置 → 对刀配置** 中提供精度/节拍权衡选项 **`自动对刀测量检测`（`INI[159]`）**：
- **`0` 两次测量（推荐高精度模式）**：测头首先以 **直线/旋转快速测量速度（`TOOL_SET[62]` / `TOOL_SET[23]`）** 接近边缘粗触发，随后微量脱开并以 **慢速测量速度（`TOOL_SET[63]` / `TOOL_SET[69]`）** 执行高精度二次精碰，消除快速惯性过冲误差；
- **`1` 一次测量**：粗碰捕获后直接锁存坐标，缩短单件节拍时间。
