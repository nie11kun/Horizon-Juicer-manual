第 1 章 软件入门与路径配置

HorizonJuicerCreator 是 Horizon-Juicer 标准数控磨床代码库的专用工程配置与裁剪工具。由于单一的 Source_Library 源码库同时包含了外螺纹、内螺纹、丝锥、蜗杆、磨削中心（复合外圆/端面/台阶）、多种轴系修整器以及不同西门子系统版本的代码与界面资源，直接将整个源码库传入机床既冗余又容易因未启用硬件分支导致报错。

通过 HorizonJuicerCreator.exe，工程师只需在图形界面勾选当前设备的实际机械结构与电气配置，即可在 1 分钟内自动完成以下工程化构建：

  1. 条件编译裁剪：依据 ;ifIs...Begin / End 及单行 ;ifIs... 标记，精确剥离无关代码分支；
  2. 文件筛选与重命名：仅提取匹配当前机型的 .SPF 子程序、.com 界面脚本与对应分辨率的 ico 图标包，并将初始化程序 INFO_INIT.MPF 自动重命名为 <机床型号>.MPF；
  3. 跨平台适配替换：针对 828D 老版、828D 新版 与 Sinumerik ONE 自动切换 siemens/oem 路径，并在选择 Sinumerik ONE 时自动执行 oneReplace.json 信号替换与屏幕尺寸映射；
  4. 本地配置记忆：每次退出或保存配置时自动同步写入当前用户主目录下的 HorizonJuicerCreator.json，便于多批次同型机床快速复用。
